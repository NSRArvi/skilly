# KriyaKarak Benchmark & Feature Reference Rule

When building features, UI components, discovery workflows, or marketplaces in this project (**Skilly**), reference the comprehensive benchmark study of **KriyaKarak** (`https://kriyakarak.com/`).

Full documentation is stored in:
`docs/references/kriyakarak-analysis.md`

### Key Reference Highlights for Skilly:
1. **Design System**:
   - Primary Brand Blue: `#0d5bff` / `#407bff`
   - Neutrals: `#222222`, `#f7f7f7` cards, `#ffffff` background
   - Typography: `"DM Sans"`, `"Noto Sans Bengali"`, `"Kalpurush"`
   - Aesthetics: Rounded-2xl cards, subtle borders (`#e0e0e0`), 3D curved portfolio carousel.
2. **5 Major Category Hubs (120+ professions)**:
   - Entertainment (বিনোদন)
   - Tech Experts (প্রযুক্তি বিশেষজ্ঞ)
   - Strategists & Consultants (স্ট্র্যাটেজিস্ট ও পরামর্শদাতা)
   - Beauty & Wellness (সৌন্দর্য এবং সুস্থতা)
   - Specialized Professionals (বিশেষায়িত প্রফেশনাল)
3. **Core Marketplace Features**:
   - **Dual Verification**: Identity Verified (NID/Passport) vs Verified Professional (Portfolio/Skill review).
   - **Talent Tiers**: "Top Rated", "Best Seller", "Rising Star".
   - **Hybrid Model**: Fixed-price service bookings with calendar + custom job board (`/jobs`) with BDT budget and localized locations.
   - **FinTech**: bKash instant payouts & SSLCommerz gateway integration with escrow.
   - **Seller Tier Calculator**: Free tier (10 tx/mo, 10k BDT withdraw limit, 2GB storage) + paid/reward storage upgrades.
